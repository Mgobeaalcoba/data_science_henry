# Clase 07 — Aprendizaje No Supervisado I

**Caso**: segmentar clientes de un retail (dataset clásico "Mall Customers") como paso previo a un futuro sistema de recomendación.

**Dataset**: `data/Mall_Customers.csv`

**Notebook**: `notebooks/clustering_mall_customers.ipynb` — resuelve lo obligatorio de `docs/homework.md`:
1. Carga y limpieza básica, estandarización de variables numéricas
2. K-Means probado con al menos 3 valores de k
3. Selección de k con método del codo + coeficiente de silueta
4. Visualización 2D de los clusters con PCA
5. Interpretación breve de cada segmento

**Resultado de referencia**: k=6 según silueta; perfiles de cliente descriptos en la conclusión del notebook.
