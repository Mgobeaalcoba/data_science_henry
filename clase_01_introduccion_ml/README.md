# Clase 01 — Introducción al Machine Learning

**Caso**: RetailBoost, un e-commerce ficticio, quiere predecir si un cliente va a comprar (`compró=1/0`) según edad, ingresos, región y frecuencia de visitas. Antes de poder entrenar ese clasificador hace falta un buen EDA.

**Dataset**: `data/retailboost_customers.csv`

**Notebook**: `notebooks/eda_retailboost.ipynb` — resuelve la consigna obligatoria de `docs/homework.md`:
1. Carga y exploración inicial del dataset
2. Distribuciones de variables numéricas y categóricas
3. Limpieza de nulos (imputación o descarte, justificado)
4. Matriz de correlación y discusión de redundancias
5. Normalización de numéricas + encoding de categóricas
6. Selección preliminar de features
